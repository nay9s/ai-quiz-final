Quiz v9

วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. ดับเบิลคลิก index.html
3. ไม่ต้องใช้ไฟล์ .bat และไม่ต้องเปิดเซิร์ฟเวอร์

ไฟล์สำคัญ
- index.html            โครงสร้างหน้าเว็บ
- styles.css            รูปแบบและหน้าตาของเว็บไซต์
- app.js                การทำงานของ Quiz
- questions-data.js     คำถามและตัวเลือกที่เว็บไซต์ใช้งานจริง
- answers-data.js       เฉลยที่เว็บไซต์ใช้งานจริง
- questions.json        สำเนาข้อมูลคำถามรูปแบบ JSON
- answers.json          สำเนาเฉลยรูปแบบ JSON
- assets/               รูปภาพประกอบคำถาม

การแก้เฉลย
แก้ที่ไฟล์ answers-data.js เท่านั้นเมื่อเปิดเว็บไซต์ด้วยการดับเบิลคลิก index.html

ตัวอย่าง:
  "history-1": "D", // D — Community เหมาะสมกับการพัฒนาด้าน AI มากที่สุด

A = ตัวเลือกแรก
B = ตัวเลือกที่สอง
C = ตัวเลือกที่สาม
D = ตัวเลือกที่สี่

เหตุผลที่มี answers.json และ answers-data.js
เบราว์เซอร์ส่วนใหญ่ไม่อนุญาตให้ JavaScript fetch ไฟล์ JSON อัตโนมัติจาก file://
ดังนั้นเว็บไซต์แบบดับเบิลคลิกจึงใช้ answers-data.js เป็นแหล่งข้อมูลจริง ส่วน answers.json เป็นสำเนาที่อ่านง่ายหรือใช้เมื่อนำเว็บไปเปิดผ่านเซิร์ฟเวอร์

เวอร์ชันนี้จัดรูปแบบและย่อหน้าใหม่แล้ว เพื่อให้อ่านและแก้ไข source code ได้ง่ายขึ้น

จัดการ Quiz ผ่าน UI
==================
1. เปิด admin.html หรือกดจัดการ Quiz บนหน้าแรก
2. เพิ่มบท / เพิ่มคำถาม แก้ตัวเลือก A–D และเลือกเฉลย
3. กดตรวจสอบ / ดู JSON แล้วดาวน์โหลด quiz-data.json
4. สำหรับ GitHub Pages ให้แทนที่ quiz-data.json ใน repository และ commit เว็บจะอ่านไฟล์นี้เมื่อเปิดผ่าน HTTP/HTTPS
5. สำหรับเปิด index.html โดยตรงจากเครื่อง ให้ดาวน์โหลดและแทนที่ questions-data.js และ answers-data.js ทั้งสองไฟล์
6. นำเข้าได้ทั้ง quiz-data.json หรือเลือก questions.json และ answers.json พร้อมกัน
7. ใส่รูปเป็น path เช่น assets/example.png และอัปโหลดรูปไปยัง assets/ ด้วย
ฉบับร่างบันทึกในเบราว์เซอร์ ไม่ได้ส่งขึ้น GitHub อัตโนมัติ หน้าจัดการนี้เป็นเครื่องมือแก้ไฟล์ของเว็บ static ไม่มีระบบบัญชีหรือเซิร์ฟเวอร์หลังบ้าน
ประวัติใหม่เก็บข้อมูลคำถามและเฉลย ณ เวลาส่งคำตอบ ประวัติเก่าใช้ข้อมูลปัจจุบันตามเดิม

หน้าทำแบบทดสอบแบบใหม่
==================
- เลือกฝึกเรียนรู้เพื่อดูเฉลยทีละข้อ หรือลองสอบเพื่อดูเฉลยหลังส่ง
- ลองสอบเลือกไม่จำกัดเวลาหรือ 10/20/30/60 นาทีได้ เมื่อครบเวลาส่งคำตอบอัตโนมัติ
- คำตอบ ตัวเลือกที่สลับ ข้อที่ปักหมุด และตำแหน่งคำถามบันทึกในเบราว์เซอร์เครื่องเดิม
- กดพักไว้ก่อน หรือปิดหน้า แล้วกลับมากดทำต่อจากเดิมบนหน้าแรก
- หากชุดคำถามหรือเฉลยเปลี่ยน ชุดที่พักไว้จะไม่ถูกนำกลับมาใช้กับข้อมูลใหม่
- ปักหมุดข้อที่ไม่มั่นใจ และเปิดภาพรวมข้อทั้งหมดเพื่อข้ามไปยังข้อที่ต้องการ
- ผลคะแนนแยกรายบท พร้อมเริ่มรอบฝึกจากข้อผิด/ยังไม่ตอบ หรือข้อที่ปักหมุด
